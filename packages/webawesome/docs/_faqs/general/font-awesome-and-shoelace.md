Web Awesome comes from the team at <a href="https://fontawesome.com" target="_blank" rel="noopener noreferrer">Font Awesome</a>, and it's the next major version of <a href="https://shoelace.style" target="_blank" rel="noopener noreferrer">Shoelace</a>. If you have a working Shoelace 2.x project, the <a href="/docs/resources/migrating-from-shoelace">migration guide</a> walks through the upgrade component by component.
