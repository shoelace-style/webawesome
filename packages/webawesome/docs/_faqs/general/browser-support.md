question: Which browsers does Web Awesome support?

- **Browsers:** the latest two major versions of Chrome, Safari, Edge, Firefox, and Opera
- **Screen readers we test with:** NVDA in Chrome and Firefox, VoiceOver in Safari

Our <a href="/docs/resources/browser-support">Browser Support Policy</a> has the details, including how we handle older browsers.
