There's a <a href="https://github.com/shoelace-style/webawesome/security/policy" target="_blank" rel="noopener noreferrer">security policy</a> for exactly this. It names the address to write to and the subject line that flags your report as a security issue. We'll respond as soon as we can and keep you updated while it's being handled.
