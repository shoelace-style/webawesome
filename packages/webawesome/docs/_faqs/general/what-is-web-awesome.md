Web Awesome is an open source library of UI components from the team at <a href="https://fontawesome.com" target="_blank" rel="noopener noreferrer">Font Awesome</a>. It's built on standard web components, so it works with any framework, and it works in plain HTML with no framework at all. The core of it is free and always will be. Start with the <a href="/docs/">Installation Guide</a>.
