---
question: Should I use the CDN or npm?
order: 10
synonyms: [install, getting started, script tag, bundler, package, cdn, self-host]
source: webawesome/docs/docs/index.md
---

The CDN is the easiest way to start: paste a couple of lines into your <code>&lt;head&gt;</code> and you can use any component. Install from npm instead if you'd rather import components in your JavaScript, since importing only the ones you use keeps your bundle as small as possible. You can also download the files and self-host them. The <a href="/docs/">Installation Guide</a> walks through all three.
