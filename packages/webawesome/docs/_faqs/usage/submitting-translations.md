---
question: Can I add or fix a translation?
order: 60
synonyms: [translation, localization, language, locale, i18n]
source: webawesome/docs/docs/localization.md
---
Please do. Translations live in <code>src/translations</code> in the GitHub repo, and you can edit them right there in the browser if you'd rather not clone anything. Send it as a pull request when you're done. Regional translations are welcome too, so a German (Switzerland) file is worth submitting even when a German one already exists. One thing worth knowing before you start: this mechanism translates what's inside our components, not the content of your app. <a href="/docs/localization">Localization</a> has the full picture.
