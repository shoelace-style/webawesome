---
question: Can I use my Font Awesome Pro icons with Web Awesome?
order: 40
synonyms: [font awesome, kit code, icons, pro icons, wa-icon]
source: webawesome/docs/docs/index.md ("Using Font Awesome Pro & Pro+")
---
Yes. Provide your Font Awesome kit code with the <code>data-fa-kit-code</code> attribute or the <code>setKitCode()</code> method, then use your Pro and Pro+ icons through <a href="/docs/components/icon"><code>&lt;wa-icon&gt;</code></a>. Both snippets are on the <a href="/docs/">Installation Guide</a>.
